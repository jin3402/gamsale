# 겜세일 — 포트폴리오 노트

이 문서는 이력서·포트폴리오·면접용으로 프로젝트를 짧게 설명하기 위한 메모입니다.  
상세 기능·실행 방법은 [README.md](../README.md)를 보세요.

## 한 줄 소개

토스 앱인토스 WebView 미니앱으로, Steam·Epic·Xbox·PlayStation·Nintendo 할인 게임을 모아 보여주는 큐레이션 서비스.

## 내가 한 일

- React + TypeScript + Vite 기반 미니앱 구조 설계
- TDS(`@toss/tds-mobile`) UI로 피드·필터·액션시트·위시리스트 구현
- CheapShark 실시간 연동 + 콘솔 스토어 CORS 대응용 빌드 스냅샷 파이프라인
- 배너/전면 광고, 진입형 프로모션 포인트 지급 연동
- 상위 노출 셔플, 150개 이후 지연 로딩, 닌텐도 성인 콘텐츠 필터

## 강조할 포인트 (면접용)

1. **플랫폼 제약을 제품으로 해결**  
   WebView CORS 때문에 콘솔 스토어를 직접 못 부르니, `prebuild` 스냅샷으로 운영 품질을 맞춤.
2. **부하를 미룬 무한 스크롤**  
   처음부터 전량 fetch하지 않고, 사용자가 150개 이상을 본 뒤에만 Steam/Epic 페이지를 추가 로드.
3. **수익화·성장까지 한 흐름**  
   단순 목록이 아니라 광고·프로모션·공유·스토어 이동까지 실제 미니앱 운영 시나리오를 구현.

## 기술 키워드

`Apps in Toss` · `WebView` · `TDS` · `React` · `TypeScript` · `Vite` · `CORS` · `Snapshot` · `Interstitial Ad` · `Promotion Reward`
